# Epiphyte-Shortfalls
This is the repository for (Carmona-Higuita et al., 2025) Data Shortfalls on Vascular Epiphytes in the Neotropics 

The 'data' directory contains some of the dataset necessary to conduct some of the analyses (other data are generated within the script).
The 'r_scripts' directory contains the R scripts to perform the analyses and plot the results.
The 'figures' direrctory contains plots generated with the script (NOTE: the final figures were obtained by using QGIS).
The 'output' directory contains the output files of the code.
The 'interim' directory saves intermediate outputs here.
The 'wgsrpd-master' directory contains map polygons.
